# /echeances : piloter les dates limites

## Garde-fous

- Commande informative uniquement : aucune télédéclaration, aucune démarche en ligne, aucun paiement, jamais.
- Un ajout ou une modification d'échéance n'est enregistré qu'après validation de l'utilisateur.
- Les obligations réelles (dates exactes, régimes) relèvent du cabinet comptable : en cas de doute, formuler la question à lui poser.

## Déroulé

1. Lire la table `echeances` : à venir sous 60 jours, et dépassées non marquées « faite ».
2. Croiser avec les documents récents indexés : une déclaration récurrente vue dans les documents (TVA mensuelle, CFE, acompte d'impôt, assemblée annuelle…) qui n'a pas son échéance en table → proposer de l'ajouter (avec périodicité).
3. Les échéances passées se traitent **en un seul tableau** (date, structure, échéance, justificatif trouvé le cas échéant), suivi d'une seule question : « 1. Toutes les marquer faites (ma recommandation si les justificatifs sont là) / 2. Les reprendre une par une ». Jamais une question par échéance sans que l'utilisateur ait choisi le pas à pas.

## Restitution

Tableau : date · structure · échéance · statut · document lié le cas échéant. Puis les propositions d'ajout, groupées dans un même tableau avec une recommandation par ligne, et une seule question pour l'ensemble.
