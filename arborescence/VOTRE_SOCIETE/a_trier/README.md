# a_trier

Déposez ici vos nouveaux documents, en vrac, sans les renommer. L'assistant s'occupe du reste : il les lit, les qualifie, propose un nom et une destination, et attend votre accord.

Ensuite, lancez la commande **traiter-a-trier** (`/traiter-a-trier` avec Claude Code et Gemini CLI, `$traiter-a-trier` avec Codex, ou simplement « traite mes documents à trier »).

Ce fichier est un repère posé par le kit : il n'est pas indexé et ne compte pas comme un de vos documents.
