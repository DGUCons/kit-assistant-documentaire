# a_supprimer

Documents mis de côté, jamais effacés : contenus qui se ressemblent, versions successives, fichiers devenus inutiles. Chaque fichier est accompagné d'un `.txt` qui explique pourquoi il est là et où se trouve l'original conservé.

C'est vous qui décidez de leur sort, quand vous voulez. L'assistant ne vide jamais ce dossier.

À ne pas confondre avec la corbeille : seul un doublon prouvé (empreinte identique, original conservé et indexé) y part directement, dans la corbeille de votre système ou dans le dossier `_corbeille/` du dossier racine.

Ce fichier est un repère posé par le kit : il n'est pas indexé et ne compte pas comme un de vos documents.
