# a_valider

L'assistant place ici les documents dont le classement est incertain (société, année ou type), avec un fichier `.txt` qui explique le doute et la qualification qu'il proposait. C'est vous qui tranchez, quand vous avez le temps.

Dites-lui simplement « vide mon a_valider » : il reprendra les cas un par un avec vous.

Ce fichier est un repère posé par le kit : il n'est pas indexé et ne compte pas comme un de vos documents.
